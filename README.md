# ♻️ Waste Segregation Using Machine Learning — CNN Image Classifier

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![TensorFlow](https://img.shields.io/badge/TensorFlow-2.13%2B-orange)
![License](https://img.shields.io/badge/License-MIT-green)

A deep-learning image classifier that looks at a photo of a waste item and
identifies its type — **cardboard, glass, metal, paper, plastic or trash**.
It is the software "brain" of an automated waste-segregation system: the class
prediction decides which bin the item belongs to, and low-confidence
predictions are **flagged for manual review** instead of being wrongly sorted.

## ✨ Key ideas

| Idea | Why it matters |
|---|---|
| **Transfer learning** (MobileNetV2 pre-trained on ImageNet) | 90%+ accuracy with only ~2,500 images, instead of needing millions |
| **Two-phase training** — frozen base first, optional fine-tuning after | Fast, stable training; fine-tuning squeezes out the last few % |
| **Data augmentation** (flip / rotate / zoom / brightness) | Free extra training images → the model generalises instead of memorising |
| **Confidence threshold at inference** | The classifier *never guesses*: below 80% confidence it asks for a human |
| **Honest evaluation** — confusion matrix + per-class precision/recall | Shows exactly *which* waste types get confused, not just one accuracy number |

## 🧠 How it works

```
raw images            ┌──────────────────────────────────────────────┐
(data/raw/<class>/)   │  prepare_data.py  →  70 / 15 / 15 split      │
                      └──────────────────┬───────────────────────────┘
                                         ▼
                      ┌──────────────────────────────────────────────┐
                      │  train.py                                    │
                      │  MobileNetV2 (frozen) ──► GAP ─► Dropout ──► │
                      │  Dense(6, softmax)          [head training]  │
                      │  then (optional) fine-tune top 30 layers     │
                      └──────────────────┬───────────────────────────┘
                                         ▼
                      ┌──────────────────────────────────────────────┐
                      │  evaluate.py  →  confusion matrix + report   │
                      │  predict.py   →  class + confidence          │
                      │                 (< 80% ⇒ manual review)      │
                      └──────────────────────────────────────────────┘
```

- **Supervised multi-class image classification** — every training image has a label.
- **Loss:** sparse categorical cross-entropy · **Optimizer:** Adam (1e-3, then 1e-5 for fine-tuning)
- **Regularisation:** augmentation, dropout (0.3), early stopping (patience 3).

## 🚀 Quickstart

```bash
git clone https://github.com/Akash-7188/waste-segregation-ml.git
cd waste-segregation-ml

python -m venv .venv
source .venv/bin/activate          # Windows:  .venv\Scripts\activate
pip install -r requirements.txt
```

**1. Get the dataset** (see [Dataset](#-dataset) section) and place it as
`data/raw/<class_name>/*.jpg`.

**2. Create the splits**
```bash
python src/prepare_data.py
```

**3. Train**
```bash
python src/train.py --epochs 20            # phase 1: head training
python src/train.py --epochs 5 --finetune  # phase 2: optional fine-tuning
```
💡 No GPU? Open the repo in [Google Colab](https://colab.research.google.com)
(Runtime → Change runtime type → T4 GPU) — the same commands work there.

**4. Evaluate**
```bash
python src/evaluate.py
```

**5. Predict on your own photos**
```bash
python src/predict.py --image path/to/photo.jpg
```
Example output:
```
image                            prediction     confidence  status
---------------------------------------------------------------------
plastic_bottle.jpg               plastic            98.3%   OK
crushed_can.jpg                  metal              76.4%   LOW CONFIDENCE -> manual review
```

**6. (Optional) Browser demo**
```bash
pip install gradio
python app.py
```

## 📦 Dataset

Primary dataset: **[TrashNet](https://github.com/garythung/trashnet)** (~2,527 images, 6 classes):

| Class | Images | | Class | Images |
|---|---|---|---|---|
| paper | 594 | | plastic | 482 |
| glass | 501 | | metal | 410 |
| cardboard | 403 | | trash | 137 |

Alternatives / additions (Kaggle): *Garbage Classification*, *Garbage
Classification V2* (10 classes, ~19.7k images), *waste-pictures* (34 classes).

> Images are **not** committed to this repo (size + licensing). Download the
> zip, extract it and copy the six class folders into `data/raw/`.
> If you improve the model with your own photos, commit only the code and
> results, not the images.
